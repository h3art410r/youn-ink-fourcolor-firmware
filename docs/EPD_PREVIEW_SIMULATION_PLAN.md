# 刷机前屏幕预览

目标是在刷机前检查墨水屏页面布局，减少等待设备慢速刷新的迭代。

## 当前状态

天气页的最小主机端仿真已跑通：它编译固件实际使用的 `WeatherRenderer`、RawDraw 和字体资源，使用固定离线天气数据渲染 400×300 framebuffer，再导出 PNG。它不是设备截图，也不模拟电子纸刷新或整机交互；页面标题与时间由预览入口补画。

## 快速开始

运行 `python firmware/tools/preview_weather.py`，默认生成 `firmware/build-s3/preview/weather.png`。依赖、输出和精度范围见[天气页仿真预览快速指南](WEATHER_PREVIEW_QUICKSTART.md)。

## 后续可扩展项

- 增加无数据、缺少空气质量、超长城市名等固定样例。
- 将应用实际使用的状态栏和页面边框也接入主机预览，减少入口手工绘制部分。
- 为每个关键样例保存图像或检查颜色、边界和内容区域，作为布局回归检查。
- 再把其他页面 Renderer 接入同一主机端预览程序。
